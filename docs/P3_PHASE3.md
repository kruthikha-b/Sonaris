## Overview

Phase 3 establishes the **acoustic-to-geographic localization foundation** for SONARIS. It takes object detections generated by P1's YOLO model and converts them into physical coordinates and real-world positions.

### The DRISHTI-SSS Metadata Reality

A rigorous audit of the benchmark DRISHTI-SSS dataset (P2 outputs) established that:
- **Zero geographic metadata exists in the dataset**: No GPS latitude/longitude, vessel headings, timestamps, or sonar swath range parameters are present in the image or label files.
- Fabricating fake coordinates in place of real GPS would be unscientific and break downstream integration.

### Architectural Solution: Dual-Mode Coordinate System

The P3 Phase 3 engine implements a clean, production-ready dual coordinate pipeline:
1. **Local Sonar Reference Frame (`coordinate_system = "local_sonar"`, `status = "relative"`)**:
   - Always available when the operator provides the sonar swath range (`range_m`).
   - Computes physical cross-track distance from the sonar nadir in metres (`local_x_m`) and bearing (`±90.0°`).
2. **WGS84 Geographic Reference Frame (`coordinate_system = "WGS84"`, `status = "estimated"`)**:
   - Seamlessly and automatically activates when sensor navigation metadata (`latitude`, `longitude`, `heading_deg`) is supplied.
   - Converts local cross-track offsets to geodetic WGS84 coordinates.
   - Calculates 1-sigma positional uncertainty in metres (`uncertainty_m`).

## Sonar Geometry & Coordinate Conventions

Side-Scan Sonar towfishes produce waterfall images where:
- The **horizontal axis (columns)** corresponds to range away from the towfish.
- The **nadir line (centre column)** is directly beneath the sensor.
- Left of nadir is the **Port** side; right of nadir is the **Starboard** side.
- Because SSS beams project sideways perpendicular to the towfish body, acoustic targets are detected at **±90°** from the sensor heading.

```
Port Side                               Nadir (Towfish)                         Starboard Side
Column 0 ───────────────────────────── Column W/2 ──────────────────────────── Column W-1
Bearing: -90° (Port)                                                    Bearing: +90° (Starboard)
local_x_m: -range_m                   local_x_m: 0.0                    local_x_m: +range_m
```

### Governing Formulas

```python
# Nadir and pixel offset
nadir_col_px = image_width_px / 2.0
pixel_from_nadir = (cx_norm * image_width_px) - nadir_col_px
range_per_px = range_m / nadir_col_px

# Physical distance and bearing
slant_range_m = abs(pixel_from_nadir) * range_per_px
local_x_m = pixel_from_nadir * range_per_px
bearing_deg = +90.0 if pixel_from_nadir >= 0.0 else -90.0
local_y_m = 0.0  # Along-track position requires ping timestamps/vessel speed
```

## WGS84 Geodetic Transformation

When GPS navigation data is supplied:
1. **True Geographic Bearing**:
   $$\theta_{\text{true}} = (\text{heading\_deg} + \text{bearing\_deg}) \pmod{360^\circ}$$
2. **Horizontal Displacements (metres)**:
   $$d_{\text{north}} = \text{slant\_range\_m} \cdot \cos(\theta_{\text{true}})$$
   $$d_{\text{east}} = \text{slant\_range\_m} \cdot \sin(\theta_{\text{true}})$$
3. **WGS84 Angular Offsets**:
   $$\Delta\text{lat} = \frac{d_{\text{north}}}{111320.0}$$
   $$\Delta\text{lon} = \frac{d_{\text{east}}}{111320.0 \cdot \cos(\text{radians}(\text{lat}))}$$

---

## Uncertainty Model

Positional uncertainty combines four independent error sources in quadrature (1-sigma):

$$\sigma_{\text{total}} = \sqrt{\sigma_{\text{gps}}^2 + \sigma_{\text{range\_res}}^2 + \sigma_{\text{pixel\_loc}}^2 + \sigma_{\text{heading}}^2}$$

- $\sigma_{\text{gps}}$: Sensor horizontal accuracy (`gps_accuracy_m`, defaults to 5.0m for DGPS).
- $\sigma_{\text{range\_res}}$: Sonar image resolution ($\text{range\_m} / \text{half\_width\_px}$).
- $\sigma_{\text{pixel\_loc}}$: Acoustic center ambiguity within the bounding box ($\frac{1}{2} w_{\text{bbox}} \cdot \text{range\_per\_px}$).
- $\sigma_{\text{heading}}$: Compass error propagation ($\text{slant\_range\_m} \cdot \tan(1.0^\circ)$).

## Usage Examples

### 1. Relative Mode (Dataset / Offline Benchmark)

```python
from geolocation import Detection, create_default_metadata, geolocate_detection

# 1. Prepare sensor metadata with swath range
meta = create_default_metadata(image_width_px=1024, image_height_px=512, range_m=75.0)

# 2. YOLO detection from P1
det = Detection.from_yolo_row(
    image_id="sonar_scan_042",
    class_id=2,  # shipwreck
    cx_norm=0.75,
    cy_norm=0.50,
    w_norm=0.08,
    h_norm=0.04,
    confidence=0.91,
)

# 3. Geolocate
geo = geolocate_detection(det, meta)

print(geo.coordinate_system)  # "local_sonar"
print(geo.status)             # "relative"
print(geo.local_x_m)          # 37.5 metres starboard
print(geo.bearing_deg)        # 90.0°
```

### 2. Geographic Mode (Live Survey / Navigation Input)

```python
from geolocation import Detection, SonarMetadata, geolocate_detection

# Metadata including vessel GPS and heading
meta = SonarMetadata(
    image_width_px=1024,
    image_height_px=512,
    range_m=75.0,
    latitude=15.4989,
    longitude=73.8278,
    heading_deg=45.0,
    gps_accuracy_m=2.0,
)

geo = geolocate_detection(det, meta)

print(geo.coordinate_system)  # "WGS84"
print(geo.status)             # "estimated"
print(f"Target Lat: {geo.latitude:.6f}, Lon: {geo.longitude:.6f}")
print(f"Uncertainty: ±{geo.uncertainty_m:.2f} m")
```

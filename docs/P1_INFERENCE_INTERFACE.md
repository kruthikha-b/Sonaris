# P1 Inference Interface

## Purpose

The P1 detection module receives a processed Side-Scan Sonar (SSS) image from P3 and returns structured object detections.

P1 does not perform sonar preprocessing or geolocation.

## Input

A path to a processed SSS image.

Supported formats include JPG and PNG.

## Model

Default trained model:

`runs/detect/models/baseline/yolo11n_baseline/weights/best.pt`

## Single-image inference

```python
from ml.detection.predict import Detector

detector = Detector(
    "runs/detect/models/baseline/yolo11n_baseline/weights/best.pt",
    device="mps"
)

result = detector.predict(
    "path/to/processed_image.png",
    confidence=0.25
)

## Batch inference

```python
result = detector.predict_batch(
    ["image1.png", "image2.png"],
    confidence=0.25
)
## P3 Integration Boundary

P3 owns sonar-specific preprocessing.

P1 consumes the processed image supplied by P3 and performs object detection.

P1 does not implement a second sonar preprocessing pipeline.

## Downstream Pipeline

Processed SSS image
→ YOLO detection
→ filtering
→ anomaly score
→ priority
→ structured output

Geolocation is handled separately by P3 and is not generated by P1.
